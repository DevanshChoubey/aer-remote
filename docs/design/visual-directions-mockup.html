Aer Remote: three design directions

Each direction shows the Home screen and the Dispenser screen with the same sample data. They all use the same token system as Home Inventory, so the one you pick becomes a single theme file and can be changed later in one place. Every direction also gets a dark mode.

A · Fresh air

Teal on near-white. Clean and airy, close to a modern system app. DM Sans throughout, flat cards.
